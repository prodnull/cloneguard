  <action>
Create `scripts/transfer_experiment.py` — a standalone experiment script that runs in `.venv-transfer/`. Structure:

**Shebang and docstring:**
```
#!/usr/bin/env python3
"""Transferability experiment: adversarial examples against MiniLM scored on DeBERTa proxy.
Run in .venv-transfer/ environment. See .planning/phases/01-transferability-gate/ for methodology.
"""
```

**Imports and paths:** Follow existing `scripts/` pattern with `sys.path.insert(0, "src")`. Import `MiniSemanticClassifier` from `cloneguard.mini_semantic`.

**CLI arguments (argparse):**
- `--limit N`: Process only first N samples (for dry-run/testing)
- `--dry-run`: Run 5 samples with PWWS only, print results to stdout, do not write file
- `--output PATH`: Override output path (default: `docs/results/transfer-experiment-YYYY-MM-DD.json`)
- `--pwws-only`: Skip TextFooler, run PWWS only (fallback if BERTScore constraint issues)

**MiniLMOnnxWrapper class (TextAttack ModelWrapper):**
- Subclass `textattack.models.wrappers.ModelWrapper`
- `__init__`: Accept `MiniSemanticClassifier` instance, store `self.model` and `self.tokenizer`
- `__call__(text_inputs: list[str]) -> np.ndarray`: For each text, tokenize with `return_tensors="np"`, `truncation=True`, `max_length=256`, `padding="max_length"`. Run `self.model._session.run(None, {"input_ids": ..., "attention_mask": ...})`. Softmax the logits. Return shape `[batch, 2]` where `[:, 0]` = P(benign), `[:, 1]` = P(malicious).
- Reference the `_score_raw` pattern from `scripts/adversarial_benchmark.py` for the ONNX inference details.

**DeBERTa proxy loader:**
- Load via `pipeline("text-classification", model="ProtectAI/deberta-v3-base-prompt-injection-v2", truncation=True, max_length=512, device=torch.device("cpu"))`
- At startup, print and record `model.config.id2label` — do NOT hard-code label strings
- Create a `score_deberta(text: str) -> dict` function that returns `{"label": str, "score": float, "is_injection": bool}` using the verified id2label mapping

**Dataset construction:**
- Load `data/benchmark/malicious_corpus.json` (185 samples)
- Pre-filter: only include samples where MiniLM raw score > 0.5 (MiniLM detects them). Log how many are skipped as "pre-misclassified" per category.
- Build TextAttack `Dataset` from `(text, 1)` tuples (label 1 = malicious)

**Attack execution (run both PWWS and TextFooler):**

For PWWS:
- `PWWSRen2019.build(model_wrapper)` — straightforward, no USE dependency
- `AttackArgs(num_examples=len(dataset), disable_stdout=True, silent=True)`
- Iterate results, collect `SuccessfulAttackResult` instances with original + adversarial text

For TextFooler (if not `--pwws-only`):
- Do NOT use `TextFoolerJin2019.build()` — it requires TensorFlow/USE
- Build manually: inspect `textattack.attack_recipes.textfooler_jin_2019` source and replicate the attack with `BERTScore` or similar torch-native semantic constraint substituted for `UniversalSentenceEncoder`
- If building a custom TextFooler proves too complex in the venv, fall back to PWWS-only and document the limitation. Do not install TensorFlow.

**Transfer scoring:**
- For each successful adversarial example (from both attacks), call `score_deberta(adversarial_text)`
- Record: original text, adversarial text, attack method, MiniLM original score, MiniLM adversarial score, DeBERTa label, DeBERTa score, transfer status (True if DeBERTa says benign/safe on adversarial text)

**Transfer rate calculation:**
- `transfer_rate = transferred_count / total_adversarial_count`
- Wilson 95% CI using `scipy.stats.norm.ppf` (formula from RESEARCH.md)
- Gate decision: `transfer_rate > 0.40` = pivot, `<= 0.40` = proceed
