Modify `scripts/train_mini_model.py`:

1. **Add `--freelb` CLI flag** (store_true, default False). When set, use FreeLB training step instead of standard backward pass.

2. **Add `--dataset` CLI arg** if not already present — path to training JSONL (default: `data/training/dataset_augmented_r2.jsonl`). This allows specifying merged augmented datasets for later rounds.

3. **Implement `freelb_step()` function** per the research pattern (Zhu et al. 2020, Algorithm 1):
   - Get input embeddings via `model.encoder.embeddings.word_embeddings(ids)`
   - Initialize delta uniform(-epsilon, epsilon), requires_grad=True
   - K=3 PGD steps: forward with `inputs_embeds=embeds_init + delta`, mean_pooling, classifier, loss/K, backward(retain_graph=True), PGD ascent on delta, clamp, detach+re-enable grad
   - optimizer.step() once after loop
   - Hyperparams: epsilon=0.01, K=3, step_size=2*epsilon/K (per Li & Qiu 2021 heuristic)
   - Force float32 in FreeLB loop (MPS stability per research open question)

4. **Modify training loop** (lines 290-326): if `--freelb`, replace the `optimizer.zero_grad(); loss.backward(); optimizer.step()` block with `freelb_step()` call. Standard training path unchanged when flag is absent.

5. **Modify `forward()` method** of `PromptInjectionClassifier`: return `(logits, pooled)` tuple instead of just `logits`. Update all call sites in the training loop to unpack correctly: `logits, _ = model(ids, mask)` for training, full tuple for export.

6. **Modify `export_onnx()` function**: add `"cls_embedding"` as second output name, add dynamic axis for it, verify after export that `session.get_outputs()[0].name == "logits"` (assertion).

Create `tests/test_train_freelb.py`:
- Smoke test: import the model class, run 2 epochs on 10 synthetic samples with FreeLB, verify loss decreases
- Gradient test: verify delta is detached between K steps (mock or trace)
- Dual-output ONNX test: export a tiny model, load with onnxruntime, verify output names and shapes
- Backward compat test: verify training without --freelb still works

**Critical:** Do NOT call `optimizer.zero_grad()` inside the K-step loop. Zero once before, step once after. This is Algorithm 1 from the paper.

**Critical:** `retain_graph=True` is needed in the backward calls inside the K-step loop because the same computation graph is reused. Detach delta between steps to prevent memory growth.
