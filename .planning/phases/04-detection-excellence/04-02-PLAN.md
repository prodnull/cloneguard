<objective>
Implement MELON selective re-execution adapted from the ICML 2025 paper (arXiv:2502.05174) for CloneGuard's hook architecture. MELON fires post-fusion when confidence falls in the ambiguous zone, masks content sections, re-classifies through the semantic classifier, and compares CLS embeddings to detect divergence indicating injected content.

Purpose: Ambiguous-confidence detections (0.4-0.6) are where false positives and false negatives cluster. MELON provides a second opinion by testing whether removing suspected-injected sections changes the classification -- if it does, the removed section was driving the ambiguous signal and is likely malicious.

Output: MELONDetector module, circuit breaker, snapshot/rollback implementations for Landlock and Seatbelt adapters, engine integration, comprehensive tests.
</objective>

    **Implement snapshot/rollback for LandlockAdapter** (per D-14, Research Snapshot/Rollback section):

    CRITICAL: Landlock restrictions are additive and irrevocable at the kernel level. Snapshot/rollback captures FILE STATE (contents), NOT restriction state.

    Replace the no-op `snapshot()` at line 440 with:
    ```python
    def snapshot(self) -> dict[str, bytes]:
        """Capture file contents for writable paths before MELON execution.

        Returns dict mapping absolute path -> file bytes for each writable
        file that exists. Landlock restrictions are irrevocable; this captures
        the file state to enable content rollback, not restriction rollback.
        """
        captured: dict[str, bytes] = {}
        for path_str in self._writable_paths:
            p = Path(path_str).resolve()
            if p.is_file():
                try:
                    captured[str(p)] = p.read_bytes()
                except OSError:
                    logger.warning("snapshot: could not read %s", p)
        return captured
    ```

    Replace the no-op `rollback()` at line 444 with:
    ```python
    def rollback(self, snapshot: dict[str, bytes]) -> None:
        """Restore file contents to pre-execution state.

        Writes back the byte content captured by snapshot(). Does not
        undo Landlock restrictions (irrevocable by kernel design).
        """
        if not snapshot:
            return
        for path_str, content in snapshot.items():
            p = Path(path_str)
            try:
                p.write_bytes(content)
            except OSError:
                logger.warning("rollback: could not restore %s", p)
    ```

    If `self._writable_paths` doesn't exist as an instance attribute, check how restrict_filesystem() stores writable paths and use that attribute. The research says `self._writable_paths` exists from restrict_filesystem().

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| content -> MELON masking | Untrusted scanned content enters masking function |
| CLS embeddings -> cosine similarity | Embedding vectors from ONNX model enter comparison |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-05 | Denial of Service | MELON trigger flooding | mitigate | Circuit breaker at >15% trigger rate in sliding window of 20 calls (D-12). Once tripped, MELON disabled for session. Non-MELON path is <20ms. |
| T-04-06 | Tampering | MELON masking evasion | accept | Attacker could craft content where masking doesn't remove the injected section. This is an arms race; masking is a defense layer, not a guarantee. Honest bypass rate will be reported in D-22 adversarial eval. |
| T-04-07 | Tampering | Snapshot file content manipulation | mitigate | Snapshot captures bytes synchronously within hook handler. No concurrent access to snapshot data. Rollback restores exact bytes captured. Race condition window is within single-threaded hook execution. |
| T-04-08 | Information Disclosure | CLS embeddings leak content | accept | Embeddings are 384-dim vectors derived from content. They are not logged, stored, or transmitted. Used only for in-memory comparison. Consistent with existing MiniSemanticClassifier handling. |
| T-04-09 | Elevation of Privilege | MELON verdict upgrade bypass | accept | If MELON is disabled (circuit breaker, no ONNX), fusion verdict stands without upgrade. This is detection-only degradation, not a privilege issue. Logged when MELON unavailable. |
