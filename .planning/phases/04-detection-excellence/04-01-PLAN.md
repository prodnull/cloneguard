<objective>
Build the three-signal fusion layer that replaces the current sequential waterfall (pattern -> semantic -> sequence with early return) in DetectionEngine with a context-weighted scoring system.

Purpose: The current engine returns on the first non-clean signal, meaning semantic and sequence signals are never consulted if patterns match first. Fusion collects ALL available signals and produces a calibrated confidence score that enables the SUSPICIOUS verdict zone used by MELON (Plan 02) and better FPR control.

Output: FusionLayer module, weight profile YAML files, calibration pipeline script, engine.py refactored to collect-then-fuse, comprehensive tests.
</objective>
