<objective>
Execute 2-3 rounds of adversarial data augmentation (PWWS) + FreeLB retraining to produce a hardened v4 MiniLM model with reduced attack success rate.

Purpose: This plan transforms the tooling from Plan 01 into a hardened model by running the iterative augmentation-retrain cycle. Each round generates PWWS adversarial examples against the current model, merges them into the training set, and retrains with FreeLB. ASR is measured between rounds to track improvement and decide when to stop.

Output: Hardened v4 dual-output ONNX model (logits + cls_embedding), per-round ASR measurements, augmented training datasets with provenance.
</objective>

**Round 2 (mandatory):**

```bash

  --round 2 \
  --model-path src/cloneguard/model/mini_semantic.onnx \
  --corpus data/benchmark/malicious_corpus.json \
  --output data/training/pwws_adversarial_r2.jsonl \
  --time-limit 90
```

2. Merge: `dataset_v4_r1.jsonl` + `pwws_adversarial_r2.jsonl` -> `dataset_v4_r2.jsonl`

3. Retrain with FreeLB on merged dataset:
```bash

  --freelb
```

4. Measure ASR. Append round 2 results to `docs/results/hardening-rounds-2026-03-10.json`.

**ASR Gate after Round 2:**
- If ASR <= 35%: STOP. Skip round 3. Export final model.
- If ASR > 35%: Continue to round 3.

**Round 3 (conditional — only if ASR > 35% after round 2):**

1. Generate PWWS adversarial examples against round-2-hardened model (same pattern, `--round 3`).
2. Merge all rounds into `dataset_v4_r3.jsonl`.
3. Retrain with FreeLB.
4. Measure ASR. Append round 3 results.

**Per CONTEXT.md decision:** If 3 rounds still miss <= 35% ASR, accept and publish actual numbers. Do NOT invoke TF-IDF contingency.

