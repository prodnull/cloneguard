  <action>
Create `scripts/adaptive_pwws_benchmark.py` — a measurement-only PWWS attack against v4 ONNX. This is a thin variant of `generate_pwws_augmentation.py` that:

1. COPIES (not imports) MiniLMOnnxWrapper from generate_pwws_augmentation.py (venv isolation, same pattern as Phase 2 decision)
2. Loads the 185-sample malicious corpus from `data/benchmark/malicious_corpus.json`
3. Pre-filters: skips samples already misclassified by v4 (score < 0.5) — same as generate_pwws_augmentation.py
4. Runs PWWSRen2019 against v4 ONNX (`src/cloneguard/model/mini_semantic.onnx`)
5. Counts successes per category (samples where PWWS generated an adversarial example that flips the v4 classification)
6. Computes Wilson confidence interval on overall adaptive ASR using scipy.stats.proportion_confint
7. Does NOT write to training data directories — output goes to `docs/results/adaptive-pwws-benchmark-2026-03-10.json`
8. Does NOT merge results into any dataset

Output JSON schema:
```json
{
  "date": "2026-03-10",
  "model_version": "v4",
  "attack_method": "pwws",
  "corpus_size": 185,
  "pre_filtered_count": N,
  "pre_misclassified_skipped": N,
  "adaptive_asr": 0.XX,
  "attacks_successful": N,
  "attacks_failed": N,
  "confidence_interval": {"ci_low": 0.XX, "ci_high": 0.XX, "method": "wilson", "alpha": 0.05},
  "per_category": {"synonym_substitution": {"total": N, "evaded": N, "asr": 0.XX}, ...},
  "comparison_to_training_rounds": {
    "round_2_benchmark_asr": 0.20,
    "round_2_generation_asr": 0.317,
    "note": "Round-2 numbers measured during training; this adaptive ASR measured on final v4 model as test-time attack"
  },
  "metadata": {
    "model_version": "v4",
    "attack_method": "pwws",
    "model_path": "src/cloneguard/model/mini_semantic.onnx",
    "time_limit_minutes": 90,
    "distinguishing_note": "Adaptive attack: fresh PWWS against final v4 model. NOT the round-2 training-time ASR (20.0%)."
  }
}
```
