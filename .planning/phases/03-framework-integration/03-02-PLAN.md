<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| AGT framework -> CloneGuardInterceptor | AGT passes tool call parameters via direct Python API. CloneGuard is a sensor, not controller -- AGT makes the final governance decision. |
| MCP client -> MCPAdapter | MCP tool call requests from arbitrary MCP clients. Content is untrusted. |
| MCP server response -> MCPAdapter.scan_response() | MCP tool responses may contain injected content (RADE, log-to-leak). |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-06 | Tampering | AGT verdict mapping | mitigate | Unit tests verify every DetectionResult verdict maps to correct AGT decision. MALICIOUS must NEVER map to ALLOW. Exhaustive test matrix: detected->DENY, suspicious->CONSTRAIN, clean->ALLOW. |
| T-03-07 | Information Disclosure | AGT audit events | mitigate | AGT audit events use tool_input_hash (SHA-256), never raw tool_input. Same AuditEvent constraints as hook events (T-02-03). |
| T-03-08 | Tampering | MCP response injection | mitigate | scan_response() passes ALL text content through DetectionEngine. Non-text items skipped (no text to scan). Response scanning uses same pipeline as PostToolUse. |
| T-03-09 | Spoofing | MCP tool description poisoning (RADE) | mitigate | MCPAdapter.normalize() extracts and scans tool description field alongside tool arguments. Malicious descriptions trigger pattern detection. |
| T-03-10 | Elevation of Privilege | mcp_plugin.py backward compat | accept | Compat shim only re-imports from adapters.mcp. No new code execution path. Deprecation warning alerts users to migrate. Risk is low -- shim is read-only delegation. |
| T-03-11 | Denial of Service | AGT SDK version break | accept | Pin to >=3.0,<4.0. try/except around all AGT API calls. If SDK breaks, CloneGuardInterceptor.available returns False and before_tool_call() returns ALLOW (fail open, logged). Rationale: AGT SDK is 4 days old, API instability is expected. |
</threat_model>
