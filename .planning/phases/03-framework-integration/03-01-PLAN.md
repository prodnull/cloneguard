<objective>
Create the InputAdapter abstraction layer that decouples CloneGuard's detection engine from any specific agent platform's hook protocol. Define the InputAdapter Protocol (PEP 544), implement adapters for Claude Code, Gemini CLI, and Cursor, build the adapter registry with auto-detection, and refactor hooks.py to delegate normalization to the adapter layer.

Purpose: This is the foundation for all Phase 3 integration work. Every subsequent plan (AGT plugin, MCP middleware, CI/CD adapter) builds on this adapter abstraction. Without it, detection remains Claude Code-specific.

Output: `src/cloneguard/adapters/` package with 5 modules, refactored `hooks.py`, and comprehensive adapter tests.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Agent hook JSON -> adapter.normalize() | Untrusted JSON from agent process crosses into CloneGuard via stdin. Adapters must validate structure. |
| adapter.format_response() -> agent | CloneGuard's detection result crosses back to the agent. Must not leak internal state. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Spoofing | detect_agent_type() | mitigate | JSON structure probing uses definitive keys (hook_type vs hook_event_name). Ambiguous events fallback to GenericAdapter which scans all content -- never silently passes. |
| T-03-02 | Tampering | adapter.normalize() | mitigate | All adapters produce frozen ToolCallEvent dataclass. raw_data stored for audit but never used for detection decisions after normalization. |
| T-03-03 | Denial of Service | adapter.normalize() | mitigate | All normalize() methods wrapped in try/except at hooks.py level. Malformed JSON returns exit 0 (allow, never crash) per existing T-01-02 pattern. |
| T-03-04 | Information Disclosure | format_response() | mitigate | format_response() returns only exit_code/message (Claude), decision/reason (Gemini), permission/userMessage (Cursor). Never includes internal signals, confidence scores, or matched patterns in agent-facing response. |
| T-03-05 | Elevation of Privilege | GenericAdapter fallback | mitigate | GenericAdapter extracts content from all JSON values and scans it. Unknown agent types get FULL scanning, not bypass. |
</threat_model>
